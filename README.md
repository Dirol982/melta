# Melta — редизайн сайта

Концепт новой главной страницы для [melta.by](https://melta.by): статический сайт на HTML/CSS/JS без сборки.

Три варианта дизайна с одинаковым содержанием:

- `/` — вариант 1, «Современный»: светлый, фирменный бирюзовый, крупные карточки
- `/v2/` — вариант 2, «Мастерская»: тёплый, с засечками, акцент на истории мыловарения
- `/v3/` — вариант 3, «Яркий каталог»: бенто-сетка, цветные плитки, ориентирован на покупку

- `index.html`, `v2/`, `v3/` — разметка вариантов
- `styles.css` — стили (адаптив: десктоп, планшет, телефон)
- `script.js` — мобильное меню и форма запроса прайса
- `assets/` — изображения с текущего сайта

Форма «Получить прайс» открывает почтовую программу с готовым письмом на sales@agnex.by. Чтобы заявки приходили напрямую, подключите обработчик форм (Formspree, Getform или свой бэкенд).

Локальный просмотр — просто откройте `index.html` в браузере.
